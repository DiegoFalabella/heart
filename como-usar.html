Como colocar os infográficos novos na matéria

Os dois infográficos do Genially vão ser trocados por versões animadas. É só copiar um código e colar no lugar do código antigo. Leva uns 2 minutos.

Você não precisa subir nenhum arquivo. Os infográficos já estão hospedados. Funciona igual ao Genially: o código só "chama" o infográfico.

Passo a passo

  1. Abra a matéria no editor do site.
  2. Encontre o primeiro Genially, o do "Ciclo da dirofilariose". Ele fica logo depois dos parágrafos de introdução.
  3. Abra a edição desse bloco e apague o código antigo do Genially.
  4. Clique em Copiar código no Infográfico 1, aqui embaixo, e cole no lugar do código que você apagou.
  5. Faça o mesmo com o segundo Genially, usando o código do Infográfico 2.
  6. Abra a pré-visualização da matéria e confira se os dois aparecem e se mexem. Pronto!

Deu algum problema?

O infográfico não aparece

Confira se o código foi colado inteiro. Ele começa com <iframe e termina com </iframe>. Se faltou um pedacinho, apague e cole de novo usando o botão.

Confira também se o código foi colado num bloco de embed/HTML, o mesmo tipo de bloco onde estava o Genially, e não num bloco de texto comum.

Aparece cortado ou com tamanho estranho no celular

Alguns editores removem parte do código. Nesse caso, use esta versão alternativa no lugar (uma para cada infográfico):

Ele aparece parado, sem animar

A animação só começa quando o infográfico aparece na tela, para não pesar a página. Role até ele e espere um segundo.

Se o celular ou computador estiver com a opção "reduzir movimento" ligada, o infográfico aparece parado de propósito, mas com todo o conteúdo visível.
